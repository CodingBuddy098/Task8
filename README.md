# 🛍️ Superstore Sales Dashboard (Power BI)

This project is part of a Data Analyst Internship Task. It showcases a simple interactive dashboard built using Power BI to visualize and analyze sales data from a fictional Superstore.

## 🛠️ Tools Used

- **Power BI Desktop** – For data visualization and dashboard creation  
- **Excel (Optional)** – For viewing and preprocessing the dataset  

## 📈 Dashboard Features

- **Line Chart**: Sales trend by Month-Year  
- **Bar Chart**: Sales comparison by Region  
- **Donut Chart**: Category-wise sales distribution  
- **Slicer**: Filter data by Region or Category  
- **Color-coded visuals** to highlight top-performing segments

## 💡 Key Insights

1. **November 2023** was the month with the highest sales.
2. The **West** region led in total sales performance.
3. **Technology** products generated the most revenue overall.
4. The **Furniture** category lagged behind in total sales.
